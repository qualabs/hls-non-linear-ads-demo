## G. El test corregido, visto en rojo

No es la campaña de mutación, que es de la T-06. Son las dos roturas de un
caracter que este nivel de verificación nombra, corridas una por una sobre la
línea del default para ver que el test corregido las agarra. La línea se
restauró después de cada una y `npm test` volvió a dar 15/15 (sección B).

M-a  el default de 0 aplicado TAMBIÉN al primario
     volume: Number(source.volume ?? DEFAULT_AD_VOLUME)
     ROJO: pass 13, fail 2
       ✖ no payload of the tool carries volume: the ad comes out silent and
         the show does not     -> AssertionError: squeezebackFrame/primaryContent
       ✖ an explicit volume of 0 survives, because a silent ad is silent on purpose

M-b  el `??` cambiado por `||`
     volume: Number(source.volume || (isPrimary ? DEFAULT_PRIMARY_VOLUME : DEFAULT_AD_VOLUME))
     ROJO: pass 14, fail 1
       ✖ an explicit volume of 0 survives, because a silent ad is silent on purpose

Y una cosa que la M-b deja a la vista para la T-06: con el default del aviso en
0, un `volume: 0` explícito EN UN ELEMENTO DEL AVISO ya no distingue `??` de
`||` --las dos ramas dan 0--. Lo que separa los dos operadores ahora es un
`volume: 0` explícito EN EL PRIMARIO, cuyo default es 100. El detector se mudó
de lado con el default.
