One media playlist. Two EXT-X-DATERANGE per break on the same START-DATE, and one where the break has no linear default. Two clients, neither of which knows about the other — and the same ad space sold on both, one of them without taking the screen.

What this device declares

There is no ad presentation server behind this page. The two capabilities travel on every asset-list request, as such a server would read them, and the answer is one static file per break that always carries every option of the ad. What decides what is drawn is the library: it keeps the first option this device can show and, when none fits, plays the break’s linear default or skips it.
