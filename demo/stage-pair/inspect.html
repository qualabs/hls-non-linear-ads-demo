There is no ad presentation server behind this page. The two capabilities travel on every asset-list request, as such a server would read them, and the answer is one static file per break that always carries every option of the ad: video first, then the same campaign as a still image in another layout. What decides what is drawn is the library, in panel 4. The control above has the same modes as each player of the pair, and the combination is in the URL.
