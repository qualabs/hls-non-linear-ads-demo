Video decoders this device declares

There is no ad presentation server behind this page. qa-decoder-count is the parameter such a server would read; here the answer is baked by value, one static playlist per step, and the switch above picks which one is loaded. What is real is the request: the parameter is on it, or absent from it, exactly as the library builds it.
