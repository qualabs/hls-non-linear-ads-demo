What the player did

One playlist. One tag. Four ads, and the match never stopped.

The programme carries a single EXT-X-DATERANGE of a custom class. An unmodified hls.js plays it; a library on top reads the asset-list the tag points at, and draws each ad into the box the layout declares — over the picture, without replacing it. The primary content is never interrupted, which is why the clock in the corner keeps running through all fifty-eight seconds.

  • 4 ads in one break
  • 3 shapes: still image, concurrent video, linear at full frame
  • 0 seconds of programme replaced
